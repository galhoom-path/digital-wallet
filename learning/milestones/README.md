# Milestone review checklists

After finishing each curriculum milestone in `learning/plan.md`, run the matching checklist before starting the next milestone.

Rules (from study-template judgment):

- No checkbox without **proof** (lesson delivered, command output, or passing tests).
- Gaps → fix or schedule a catch-up lesson (`Lesson NNNa` style) — do not silently skip.
- Update `learning/progress.md` when the milestone flips to COMPLETED.
- **Shared grading rule:** concept accuracy first. If the design/logic is right but syntax is off, confirm the logic first, then correct syntax separately.
- Every checklist states a **pass bar** (minimum concrete evidence). Do not mark COMPLETED below that bar.
- Name the gap explicitly when a checkbox fails: `The part that needs one more pass is...`
