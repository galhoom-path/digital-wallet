# Digital Wallet — Mentored Coding Challenge

A hands-on training workspace for the **Digital Wallet Coding Challenge**.

Stack lock: **Laravel 13** ([release notes](https://laravel.com/docs/13.x/releases)) on **PHP 8.5**.  
Challenge scope: exact brief requirements in [`docs/requirements.md`](docs/requirements.md) — no missing mandatory items, no invented extras in the 100% checklist.

You write every line of application code. Cursor is your mentor and guide only — it never implements the challenge for you.

## Start here

1. Read [`learning/START-HERE.md`](learning/START-HERE.md)
2. Open a chat and say: **Start the current lesson**
3. Do the task yourself, then share command output / code for review

## Workspace layout

```text
.
├── README.md                 ← you are here
├── AGENTS.md                 ← mentor constitution (for the AI)
├── .cursor/rules/            ← always-on Cursor rules
├── docs/                     ← requirements, assumptions, decisions, samples
├── learning/                 ← curriculum, progress, session protocol
└── solution/                 ← Laravel deliverable (you create it in a later lesson)
```

## Roles

| You (mentee) | Mentor (Cursor) |
| --- | --- |
| Write all code under `solution/` | Explain why; recommend one engineering decision |
| Run commands and tests | Give one small actionable task per lesson |
| Own and understand the solution | Review your work; update progress with evidence |

## Rules that never bend

- No quizzes, no mandatory questions, no conversational gates before the next lesson.
- Every lesson uses the Pareto format: the ~20% of knowledge that unlocks ~80% of value *now*.
- `solution/` is the only Git repository that gets submitted. Learning files never enter it.
- Financial integrity, idempotency, constraints, concurrency, webhook durability, security, and tests are never skipped for brevity.
